Are you interested in working _on_ Gargantuan? This guide walks through how to compile and work on your own homegrown Gargantuans.
## Supported Platforms
Gargantuan works across most major operating systems, which include the latest versions of **Windows, MacOS and Linux.**

However, older OS versions may lack support for the libraries necessary for Gargantuan to run, and we do not guarantee support nor flawless installation for any of them.
## Prerequisites
### Windows
- Windows 10 and/or 11
- Vulkan SDK
DirectX 12 will eventually be supported.
### MacOS
- MacOS 26 and XCode 26
- Vulkan SDK IF you want to test Vulkan via MoltenVK
    - *Vulkan SDK comes included with glslc*

[Homebrew](https://brew.sh/) can be used to trivially install CMake, Ninja, and CCache:
```
brew install cmake ninja ccache
```
### Linux
#### Vulkan
For Gargantuan to output graphics, you'll first need a **Vulkan-capable GPU and a working driver for it.** 

The installation steps for this vary significantly with each distribution and system configuration, so this section assumes Vulkan is already properly configured.

Verify that Vulkan can detect your GPU correctly:
```
vulkaninfo --summary
```

#### Rokit
Once you have installed dependencies, install [Rokit](https://github.com/rojo-rbx/rokit) via the automated installer script with `curl`:
```
curl -sSf https://raw.githubusercontent.com/rojo-rbx/rokit/main/scripts/install.sh | bash
```

Afterwards, **restart your shell** in order for Rokit to be picked up via PATH.
## Get the Source Code
Clone the Gargantuan repository and all of its submodules using the following command:
```
git clone --recursive https://github.com/teamfireworks/gargantuan.git
```
<Aside type="caution">
	If you are an outside contributor, please clone from your own fork of Gargantuan. Team Fireworks can work on the main repository.
</Aside>
## Build Gargantuan
Move to the newly cloned Gargantuan directory, and install the tools in `rokit.toml`:
```
rokit install
```

Then, create a `build` folder inside for generated build files and binaries during compilation:
```
mkdir build
```

Gargantuan provides a [Justfile](https://github.com/teamfireworks/gargantuan/blob/main/.justfile) which is used with [Just](https://just.systems/) to simplify the build process. You can list the summary of all the available recipes with:
```
just -l
```

<Aside>
	Alternatively, you can manually run the commands inside the Justfile and replace any variables as you see fit.

	This is most important when working on Windows where commands default to PowerShell, as its awful to work with.
</Aside>

For now, use `just` to configure the project by instantiating CMake and generating the Ninja build files:
```
just configure
```

Then, compile Gargantuan:
```
just build
```

**After compilation finishes, the Gargantuan executable will be located in `build/gargantuan`!**
#### Build Options
Gargantuan includes optional [Tracy](https://github.com/wolfpld/tracy) profiling support, but it is disabled by default.

To build the Tracy tools:
```
cmake -B build -DGARGANTUAN_TRACY_TOOLS=ON
cmake --build build --target tracy-profiler tracy-capture tracy-csvexport
```

Once the tools are built and the engine is running, connect to them via `just`:
```
just run ...
./build/bin/tracy-profiler
```

`tracy-capture -o run.tracy -s 10` records without a window open, and `tracy-csvexport run.tracy` prints per-zone totals, which is how two runs get compared.

If you'd like to **completely disable Tracy,** run:
```
cmake -B build -DGARGANTUAN_TRACY=OFF
```
or:
```
just build --tracy=OFF
```

## Run Gargantuan
Once built, you can run the binary with the `gargantuan` recipe:
```
just gargantuan --help
```

Run an `assets/example` script, the `assets/testbed` project, or the `studio` project:
```
just run_example cube.luau
just run_testbed
just run_studio
```

**When you make changes in Gargantuan,** you can easily rebuild the engine and run the binary with the `fresh` recipes:
```
just fresh_example cube.luau
just fresh_testbed
just fresh_studio
```

Tests are written using the [Lest](https://lest-luau.github.io/lest/writing-tests) framework. To run the test suite, use the `test` recipe:
```
just test
```

**You're now fully ready to work on Gargantuan!** Make sure to [follow our guidelines & best practices](./contributing-to-gargantuan) for submitting contributions, and have at it :D
